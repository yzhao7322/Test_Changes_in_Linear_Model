This repository provides codes for implementing the procedure in the paper "Testing for changes in linear models using weighted residuals", by Lajos Horvath, Gregory Rice, and Yuqian Zhao.

R code:

- `dgp.R` - data-generating processes for the main simulation settings
- `tests.R` - functions to load for implementing the V and Q tests
- `demo.R` - simulation demo for models with IID, ARMA, and GARCH errors
